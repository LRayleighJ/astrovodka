astrovodka.sources.tng_source — TNGSource

Loads IllustrisTNG data from local disk. Computes per-particle HI/H2 masses using the K13 volumetric model. Inherits from SPHSource.

  • First 3 params (basePath, snapNum, subID) are positional; rest keyword-only.
  • observed_redshift: decouples K13 physics (snapshot z) from distance (observed z). Place z~0 galaxy at any redshift.
  • load_subhalo_only=True (default) is much faster than FOF group loading.
  • K13 uses 8 TNG fields: Masses, Density, InternalEnergy, SFR, NeutralHydrogenAbundance, GFM_Metals, GFM_Metallicity, Coordinates.
