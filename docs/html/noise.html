astrovodka.noise — Noise Models

Generate noise cubes. Built-in: GaussianNoise. Custom noise models derive from _BaseNoise.

GaussianNoise

__init__(self, rms=1 Jy/beam, seed=0)

Parameters:
NameTypeDescription
rmsQuantity[Jy/beam]Desired post-convolution RMS noise (default: 1 Jy/beam).
seedintRandom seed for reproducibility (default: 0).
Returns: None
Initializes self.rng = np.random.default_rng(seed).

generate(self, datacube, beam)

Parameters:
NameTypeDescription
datacubeDataCubeProvides array shape and pixel scale.
beam_BaseBeamProvides FWHM for pre/post-convolution RMS scaling.
Returns: Quantity[Jy/arcsec²]
  • Noise is added before beam convolution. The RMS is scaled up to compensate for convolution smoothing: rms_pre = rms_post × 2.19568 × √(π × σ_maj_px × σ_min_px).
  • Uses self.rng.normal() for random generation (seed-based reproducibility).

reset_rng(self)

Returns: None
Resets RNG to initial state (re-seeds with original seed). Useful for reproducible noise realizations.
Custom noise: Inherit from _BaseNoise and implement generate(datacube, beam).
