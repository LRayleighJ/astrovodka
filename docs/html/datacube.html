astrovodka.datacube — DataCube

Defines the output data cube grid: pixels, channels, and WCS. Supports construction from scratch or from an existing WCS.

Module Constants

HIfreq = 1.420405751e9 * U.Hz

HI 21-cm line rest frequency, used throughout the pipeline for Doppler conversions and WCS RESTFRQ.

Parameters:
NameTypeDescription
n_px_xintPixel count along RA axis. Even integers preferred.
n_px_yintPixel count along Dec axis.
n_channelsintNumber of spectral channels.
px_sizeQuantity[arcsec]Angular pixel size.
channel_widthQuantity[km/s | Hz]Channel width. Can be velocity or frequency.
spectral_centreQuantityCentre of spectral axis (default: 0 km/s). Set to source.vsys.
raQuantity[deg]RA of cube centroid (default: 0 deg).
decQuantity[deg]Dec of cube centroid (default: 0 deg).
stokes_axisboolInclude Stokes axis (default: False).
coordinate_frameBaseRADecFrameAstropy coordinate frame (default: ICRS).
specsysstrSpectral reference frame: 'icrs', 'gcrs', 'lsrk' (default: 'icrs').
spectral_unitstrSpectral axis unit: 'MHz' (default), 'km/s', or None (auto-detect).
Returns: None
  • All parameters are keyword-only.
  • spectral_unit='MHz' (default) converts velocity inputs to frequency. WCS CTYPE3='FREQ'.
  • spectral_unit='km/s' keeps velocity axis. WCS CTYPE3='VRAD'.
  • spectral_unit=None auto-detects from channel_width units (backward compatible).
  • Internal array _array: shape (n_px_x, n_px_y, n_channels), unit Jy/pix².

from_wcs((classmethod) input_wcs, specsys=None)

Parameters:
NameTypeDescription
input_wcsastropy.wcs.WCSExisting WCS (e.g., from a FITS header).
specsysstr | NoneSpectral reference system override.
Returns: DataCube
  • Creates DataCube matching the input WCS dimensions and pixel scales.
  • Extracts n_px_x, n_px_y, n_channels, px_size, channel_width, spectral_centre, ra, dec automatically.
  • Requires square pixels (|CDELT_RA| == |CDELT_Dec|).
  • Warns if RESTFRQ or SPECSYS are missing from input WCS.
