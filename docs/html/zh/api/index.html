astrovodka API 参考

Version 1.1.0 — 对 IllustrisTNG 星系生成模拟 HI 观测，具备宇宙学距离， 并提供四种可选的 Diemer+2018 HI/H2 模型。

这里是逐模块的接口参考。背后的概念请先看用户指南； HI/H2 物理见 HI/H2 模型；安装见 安装与环境配置。

模块

模块 说明
martini 核心流水线 — Martini 与 GlobalProfile 两个类
datacube DataCube — WCS 网格定义
sph_source SPHSource — 通用 SPH 源（红移模式 + 距离模式）
tng_source TNGSource — IllustrisTNG 源 + 可选 HI 模型
beams GaussianBeam — 望远镜波束模型
noise GaussianNoise — 噪声模型
spectral_models GaussianSpectrum、DiracDeltaSpectrum — 21-cm 谱线模型
sph_kernels SPH 平滑核（6 种，带自适应回退）
cosmology_utils 宇宙学距离与单位换算辅助函数
himodel 四种可选 HI/H2 模型（GD14/K13，体密度/投影）
data_products SubhaloDataProducts — 三维网格化 UV/DM/HI/H2
group_products GroupDataProducts — FOF group 的气体/暗物质，含 ISM/CGM/IGM 分类
L_coords 角动量对齐坐标
_illustris_tools TNG 快照数据 I/O 工具
astrovodka — mock resolved HI observations of IllustrisTNG galaxies. Generated from the Markdown sources by docs/build_html.py.
