astrovodka.sources.sph_source — SPHSource

从 SPH 粒子数组抽象出发射 HI 的天体。同时支持旧版距离模式和新的宇宙学红移模式。

模式：

  • 红移模式（新增）：设置 redshift，可选设置 cosmology。粒子按角直径距离 D<sub>A</sub> 放置到天球上（因此在任意红移下角尺寸都正确）；流量定标使用 光度距离 D<sub>L</sub>；并且 vsys = c·z/(1+z)，即与 WCS 光谱轴一致的 射电约定。
  • 距离模式（旧版）：设置 distance 与 h。计算 vsys=h×100×D + vpeculiar。 此时 D<sub>A</sub> == D<sub>L</sub> == distance，也就是未作改动的 MARTINI 行为。
  • 两者不能同时设置（会抛出 ValueError）。
  • 平滑长度必须是 FWHM（而不是核半径）。
