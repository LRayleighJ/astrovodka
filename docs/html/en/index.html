astrovodka documentation

Mock resolved HI (21 cm) observations of IllustrisTNG galaxies.

astrovodka turns SPH particle data into synthetic radio data cubes. It is a fork of MARTINI that replaces the distance calculation with proper cosmological distances and the neutral-gas partition with physically motivated HI/H₂ models.

The two things that make it not-MARTINI

Cosmological distances. D_L normalises the flux and D_A sets every angular scale, both from Planck15. They differ by (1+z)² and using the wrong one is the single most expensive mistake available here. See Two distances.

Four selectable HI/H₂ models. The Diemer+2018 pairings of Gnedin & Draine 2014 and Krumholz+ 2013, each in a volume and a projected variant, selected with one keyword. They disagree with each other by design — on one subhalo the H₂ mass differs by a factor of ~6 between K13_vol and GD14_vol — so which one you used is part of the result. See The HI/H₂ models.
