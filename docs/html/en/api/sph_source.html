astrovodka.sources.sph_source — SPHSource

Abstracts an HI-emitting object from SPH particle arrays. Supports legacy distance mode and new cosmological redshift mode.

Modes:

  • Redshift (new): set redshift + optional cosmology. Particles are placed on the sky at the angular diameter distance D<sub>A</sub> (so angular sizes are correct at any redshift); the flux scale uses the luminosity distance D<sub>L</sub>; and vsys = c·z/(1+z), the radio convention that matches the WCS spectral axis.
  • Distance (legacy): set distance + h. Computes vsys=h×100×D + vpeculiar. Here D<sub>A</sub> == D<sub>L</sub> == distance, so this is unchanged MARTINI.
  • Cannot set both (raises ValueError).
  • Smoothing lengths MUST be FWHM (not kernel radius).
