astrovodka API reference

Version 1.0.0 — mock resolved HI observations of IllustrisTNG galaxies, with cosmological distances and four selectable Diemer+2018 HI/H2 models.

This is the per-module reference. For the concepts behind it, start with the user guide; for the HI/H2 physics, see the HI/H2 models; for installation, see installation and environment setup.

Modules

Module Description
martini Core pipeline — Martini and GlobalProfile classes
datacube DataCube — WCS grid definition
sph_source SPHSource — Generic SPH source (redshift + distance modes)
tng_source TNGSource — IllustrisTNG + selectable HI model
beams GaussianBeam — Telescope beam models
noise GaussianNoise — Noise models
spectral_models GaussianSpectrum, DiracDeltaSpectrum — 21-cm line models
sph_kernels SPH smoothing kernels (6 types with adaptive fallback)
cosmology_utils Cosmological distance and unit conversion helpers
himodel Four selectable HI/H2 models (GD14/K13, volume/projected)
data_products SubhaloDataProducts — 3D gridded UV/DM/HI/H2
L_coords Angular momentum alignment coordinates
_illustris_tools TNG snapshot data I/O utilities
