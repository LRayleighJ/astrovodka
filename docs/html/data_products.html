astrovodka.data_products — 3D Gridded Data Products

Container for 3D gridded data products: UV field, DM/HI/H2 mass density in comoving real-space and redshift-space, with HDF5 I/O.

  • Loads gas (PartType0) and DM (PartType1) particles.
  • Computes K13 HI/H2 masses; grids all quantities using np.histogramdd.
  • DM particle mass is read from Header.MassTable[1] (constant for all DM particles).
  • Grid edges are in comoving ckpc/h (same as TNG coordinates).

Data Grid Attributes

All grids are (ngrid, ngrid, ngrid) float32 arrays.

AttributeUnitDescription
uv_fieldDraine unitsUV radiation field (global UVB or adaptive FFT grid).
dm_realMsun/(ckpc/h)³Comoving DM density (real space).
dm_rsdMsun/(ckpc/h)³Comoving DM density (redshift space).
hi_realMsun/(ckpc/h)³Comoving HI density (real space).
hi_rsdMsun/(ckpc/h)³Comoving HI density (redshift space).
h2_realMsun/(ckpc/h)³Comoving H2 density (real space).
h2_rsdMsun/(ckpc/h)³Comoving H2 density (redshift space).
grid_edgesckpc/hTuple of 3 edge arrays, each length ngrid+1.
metadata—Dict with redshift, hubble_h, scale_factor, grid bounds, etc.
Redshift-space formula: sx = x + vlos / (a × H(a)) where vlos is the LOS peculiar velocity [km/s], a=1/(1+z), and H(a) [km/s/Mpc] from Planck15. The shift is converted to comoving ckpc/h: Δx = vlos/(a×H(a)) × 1000 × h.
