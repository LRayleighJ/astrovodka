astrovodka.sources.sph_source — SPHSource

Abstracts an HI-emitting object from SPH particle arrays. Supports legacy distance mode and new cosmological redshift mode.

Returns: None
  • Redshift mode: set redshift + optional cosmology. Computes DL=luminosity_distance(z), DA=angular_diameter_distance(z), vsys=H(z)×DL/(1+z).
  • Distance mode: set distance + h. Computes vsys = h×100 km/s/Mpc × distance + vpeculiar.
  • Cannot set both redshift and distance (raises ValueError).
  • SPH smoothing lengths MUST be provided as FWHM (not kernel radius).
