astrovodka.sources._k13_model — K13 HI/H2 Model

Implements the Krumholz 2013 (Diemer+2018) volumetric HI/H2 model. Functions extracted from the standalone K13 catalog builder.

calc_UMW_global_Faucher11(redshift)

Parameters:
NameTypeDescription
redshiftfloatRedshift.
Returns: float [Draine units]
Global UV background from Faucher-Giguère+2011. 4th-order polynomial fit: log10UMW = -0.004292z&sup4; + 0.061446z³ - 0.358413z² + 1.204787z - 2.846354. At z=0, UMW ≈ 1.4×10-3.

get_f_neutral_H(nH_code, sfr_code)

Parameters:
NameTypeDescription
nH_codendarrayTNG NeutralHydrogenAbundance (f_HI only, Rahmati+2013 self-shielding).
sfr_codendarrayTNG StarFormationRate.
Returns: ndarray
  • Estimates fneutral = fHI + fH2 from TNG fields.
  • SF particles (SFR>0): fneutral=1 (cold ISM fully neutral).
  • Non-SF particles: fneutral ≈ fHI (H2 negligible, ~10% bias).

f_mol_K13_vol(rho_code, u_code, Z, nH_code, sfr_code, X_H, U_MW, redshift=0.0, hubble_h=0.6774, mgas=None)

Parameters:
NameTypeDescription
rho_codendarrayTNG comoving density (code units).
u_codendarrayTNG internal energy [(km/s)²].
ZndarrayMetallicity (absolute mass fraction).
nH_codendarrayNeutralHydrogenAbundance (f_HI).
sfr_codendarrayStar formation rate.
X_HndarrayHydrogen mass fraction (from GFM_Metals[:,0]).
U_MWfloat | ndarrayUV radiation field (scalar=global UVB, array=adaptive FFT).
redshiftfloatRedshift for unit conversions (default: 0).
hubble_hfloatDimensionless Hubble parameter (default: 0.6774).
Returns: tuple[f_mol, f_HI, f_H2]
  • Core K13 model. Returns three ndarrays: fmol, fHI, fH2 (fractions of total hydrogen).
  • Algorithm: fneutral → nCNM (two-phase equilibrium) → χ (radiation parameter) → τc (dust optical depth) → s (K13 Eq.6) → fmol (K13 Eq.2).
  • Clumping factor fc=5. Surface density via Jeans length: Σ=ρ×λJ.

compute_HI_mass_particle(gas_data, U_MW, redshift=0.0, hubble_h=0.6774)

Parameters:
NameTypeDescription
gas_datadictDict with keys: Masses, Density, InternalEnergy, StarFormationRate, NeutralHydrogenAbundance, GFM_Metals, GFM_Metallicity.
U_MWfloat | ndarrayUV radiation field.
redshiftfloatRedshift.

Returns: tuple[m_HI, m_H2] [code units: 1e10 M_sun/h]
  • Convenience wrapper: extracts fields from gas_data, calls f_mol_K13_vol(), computes mHI=mgas×XH×fHI.
  • GFM_Metals is handled for both 1D (mdi=0 sliced) and 2D formats.
  • Returns masses in TNG code units. Convert to Msun: multiply by 1e10/h.

compute_galaxy_fft_uv(gas_data, redshift=0.0, hubble_h=0.6774, ngrid=128, f_esc=0.1, box_expand=1.1, return_grid=False)

Parameters:
NameTypeDescription
gas_datadictDict with keys: Coordinates, StarFormationRate.
redshiftfloat
hubble_hfloat
ngridintFFT grid resolution per dimension (default: 128).
f_escfloatUV photon escape fraction (default: 0.1).
box_expandfloatAdaptive box multiplier (default: 1.1).
return_gridboolIf True, return (per_particle, grid, edges) tuple.
Returns: ndarray | tuple
  • Builds a 128³ SFR grid from star-forming particles, convolves with 1/r² kernel via FFT.
  • Interpolates back to per-particle UMW values using trilinear interpolation.
  • Always applies global UVB floor: U_MW += calc_UMW_global_Faucher11(z).
  • SFR-to-FUV conversion: 3.3×10-6 photons/s/cm²/Hz per Msun/yr (Starburst99).
  • Draine field normalization: 3.43×10-8 erg/s/cm².
  • When return_grid=True, returns (per_particle_UMW, UMW_raw_grid_3D, bin_edges_list).
