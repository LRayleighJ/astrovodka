astrovodka.martini — Core Pipeline

The Martini class orchestrates the mock-observing pipeline by connecting source, DataCube, beam, noise, spectral model, and SPH kernel.

insert_source_in_cube(self, skip_validation=False, progressbar=None, ncpu=1)

Parameters:
NameTypeDescription
skip_validationboolSkip SPH kernel accuracy checks (default: False)
progressbarbool | NoneShow tqdm progress bar. None = auto (default: None)
ncpuintNumber of parallel processes. Requires multiprocess (default: 1)
Returns: None
Notes:
  • This is the most computationally expensive step — each pixel loops over all nearby particles.
  • Parallelism uses multiprocess (dill serialization), NOT multiprocessing (pickle). Install with pip install multiprocess.
  • Parallelism is per-pixel: each worker processes one pixel independently. Memory overhead is ~1 extra cube array.
  • Mass conservation is reported: flux-summed mass should match input HI mass within ~1%.
  • Kernel validation checks that smoothing-length-to-pixel-size ratios meet accuracy bounds. Set skip_validation=True to bypass (at accuracy cost).

convolve_beam(self)

Returns: None
Notes:
  • Requires beam to be set in Martini.__init__. Warns and skips if None.
  • Uses scipy.signal.fftconvolve for FFT-based convolution (fast for large beams).
  • After convolution, padding is removed and array units change from Jy/pix² to Jy/beam.
  • Raises ValueError if the DataCube padding is insufficient (e.g., beam was changed after init).

add_noise(self)

Returns: None
Notes:
  • Requires both beam and noise to be set. Warns and skips if either is None.
  • Noise is added before beam convolution. The RMS is auto-scaled: rms_pre = rms_post × 2.19568 × √(π × σ_maj × σ_min).
  • Can be called before or after insert_source_in_cube() — unit conversion handles both cases.

reset(self)

Returns: None
Re-initializes the DataCube with zeros, keeping source + all sub-module configurations. Useful for re-running with different parameters without reloading data.

GlobalProfile

Simplified class for spatially-integrated (global) spectra only. No beam, noise, or SPH kernel needed. Particles are not spatially pruned — all particles within the spectral range contribute.
