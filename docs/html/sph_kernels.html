astrovodka.sph_kernels — SPH Smoothing Kernels

Smooth SPH particles onto the pixel grid. All public kernel classes include adaptive fallback: when the pixel-to-smoothing-length ratio is too large, they automatically fall back to DiracDeltaKernel then GaussianKernel(truncate=6). Use underscore-prefixed versions (e.g., _CubicSplineKernel) for raw kernels without fallback.

Key Concepts

  • min_valid_size: Minimum smoothing length (in pixels) for 1% kernel integral accuracy. Below this, the constant-amplitude approximation breaks down and the kernel falls back.
  • size_in_fwhm: The kernel extent in FWHM units. Determines how many pixels a particle can influence.
  • _px_weight(dij, mask): Called internally to compute kernel integrals. Returns per-particle pixel weights (units of pix-2).
  • Skip validation: Use Martini.insert_source_in_cube(skip_validation=True) to bypass accuracy checks.

find_fwhm(f: Callable) -> float

Utility function. Solves for the FWHM of a kernel function via scipy.optimize.fsolve. Assumes maximum at f(0) and symmetry.
