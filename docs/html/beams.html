astrovodka.beams — Telescope Beam Models

Models the telescope beam. Built-in: GaussianBeam (elliptical 2D Gaussian). Custom beams can be derived from _BaseBeam.

GaussianBeam

__init__(self, bmaj=15 arcsec, bmin=None, bpa=0 deg, truncate=4.0)

Parameters:
NameTypeDescription
bmajQuantity[arcsec]Beam major axis FWHM (default: 15 arcsec).
bminQuantity[arcsec] | NoneBeam minor axis FWHM. None = circular, equals bmaj.
bpaQuantity[deg]Position angle, East of North (default: 0 deg).
truncatefloatTruncation radius in FWHM units (default: 4.0). Must be ≥ 2.
Returns: None
  • The beam is integrated over each pixel using a RectBivariateSpline (cubic) for accurate pixel-integrated values.
  • Area computed as π×bmaj×bmin / (4×ln2) (Gaussian-equivalent).
  • The kernel is stored as self.kernel (2D dimensionless array) after init_kernel().

needs_pad(self)

Returns: tuple[int, int]
Returns (pad_x, pad_y) = half the kernel size. Used to add padding to DataCube before convolution.
Custom beams: Inherit from _BaseBeam and implement: f_kernel() (returns callable), kernel_size_px() (returns half-size), and optionally init_beam_header().
