astrovodka.sources._illustris_tools — TNG Data I/O

Internal utilities for reading IllustrisTNG simulation data. Reproduced from the illustris_python toolkit.

loadHeader(basePath, snapNum)

Parameters:
NameTypeDescription
basePathstrTNG data root.
snapNumintSnapshot number.
Returns: dict
Loads group catalog header. Returns dict with keys: HubbleParam, Time, Redshift, BoxSize, etc.

loadSingle(basePath, snapNum, haloID=-1, subhaloID=-1)

Parameters:
NameTypeDescription
basePathstr
snapNumint
haloIDintHalo ID (mutually exclusive with subhaloID).
subhaloIDintSubhalo ID (mutually exclusive with haloID).
Returns: dict
Loads all group catalog fields for one halo/subhalo. Returns keys: SubhaloPos, SubhaloVel, SubhaloGrNr, SubhaloLenType, etc.

loadSubset(basePath, snapNum, partType, *, fields, subset=None, mdi=None, sq=True, float32=False)

Parameters:
NameTypeDescription
partTypestr | intParticle type: 'gas'(0), 'dm'(1), 'star'(4), 'bh'(5), etc.
fieldslist[str]Field names to load.
subsetdict | NoneSubset specification from getSnapOffsets.
mdilist[int|None] | NoneMulti-dimensional index per field. None = load all columns.
sqboolIf True and single field, return array instead of dict.
float32boolLoad float64 as float32 (save memory).
Returns: dict | ndarray
Loads subset of fields for a particle type. Handles multi-file chunks automatically.
