astrovodka.spectral_models — 21-cm Spectral Line Models

Models the 21-cm line profile per SPH particle. Built-in: GaussianSpectrum, DiracDeltaSpectrum.

  • When sigma='thermal', width is computed per-particle from source.T_g: σ = √(kBT/mp).
  • Spectrum evaluated as 0.5 × [erf((b-v)/(σ√2)) - erf((a-v)/(σ√2))] where a,b are channel edges.

Delta-function model. All flux goes into the single channel containing the particle velocity.
How spectra work: Each particle's spectral line is integrated over each channel. The dimensionless result is multiplied by mHI_g / D_L² / dv and converted to Jy using M_HI/M_sun = 2.36×10&sup5; × (D_L/Mpc)² × (S_21/Jy km/s).
Custom spectra: Inherit from _BaseSpectrum. Implement half_width(source) and spectral_function(a, b, vmids, extra_data). Optionally override get_spectral_function_extra_data().
